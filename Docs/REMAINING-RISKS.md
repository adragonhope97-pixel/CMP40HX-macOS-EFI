# REMAINING-RISKS(v1.1)

1. **BAR1 64MB 超小窗**:上游仅公开 256MB 修复实证;64MB 初始化路径待 L4(阶段 4)。
2. **无头 hold 行为**:无显示头时 boot-hold 是否按超时释放,无公开案例;`-nvoff` 救援在位。
3. **26.7.2 ABI 兼容**:预检只验 minOS;实际内核 ABI 需安装后验证。
4. **P630 加速修复**(BUG-P630-001):变更计划(06)就绪未获批;不修复则 CMP Metal 设备不可见(依赖链)。
5. **PolyForm 非商业许可**:商用前必须合规评估。
6. **音频/USB**:功能缺失,修复需 L4 试错循环。
7. **BIOS 为第三方改版**:Above4G/CSM 状态 UNKNOWN,进 BIOS 人工确认。
